# Aurora · лёгкий веб-плеер

Музыка из интернета, **без рекламы**, **без ключей API** и **без тяжёлых зависимостей**.
Один `index.html`, один CSS и четыре обычных JS-файла — ни сборки, ни фреймворка,
ни стороннего шрифта с CDN.

![Стек](https://img.shields.io/badge/deps-0-green) ![Размер](https://img.shields.io/badge/payload-~128_KB-blue)

---

## Откуда музыка

| Источник | Что даёт | Почему без рекламы |
|---|---|---|
| [**Audius**](https://audius.co) | Полные треки напрямую от исполнителей: тренды по жанрам, поиск | Децентрализованная платформа, поток идёт без вставок |
| [**Internet Archive**](https://archive.org) | Нетлейблы, живые концерты, CC-альбомы целиком | Общественный архив, свободные лицензии |

Ключи API не нужны ни там, ни там. Audius отдаёт прямую ссылку на поток прямо
в карточке трека, archive.org — стабильный адрес `archive.org/download/{id}/{file}`.

## Запуск

```bash
python3 -m http.server 8000 --bind 0.0.0.0     # или npm start
```

и откройте `http://localhost:8000`. Сервер отдаёт только статику — весь трафик
с музыкой идёт из браузера напрямую к источникам.

Можно и вовсе без сервера: скрипты обычные, не ES-модули, поэтому `index.html`
открывается и двойным кликом с диска.

## Что умеет

- **Тренды по жанрам** (Audius) — 14 жанров, от эмбиента до драм-н-бейса
- **Поиск** по трекам и исполнителям
- **Internet Archive** — подборки (нетлейблы / живые концерты / вся музыка /
  мировая музыка / 78 оборотов), открытие альбома со списком треков
- **Очередь** с добавлением, удалением и переходом по клику
- **Избранное и история** — в `localStorage`, никуда не отправляются
- **Перемешивание**, повтор очереди и повтор одного трека
- **Полноэкранный вид трека** с круговым визуализатором
- **Media Session API** — кнопки на клавиатуре, в шторке и на гарнитуре
- **Таймер сна** (15 / 30 / 60 мин) с плавным затуханием звука
- **Тема подстраивается под обложку** — доминирующий цвет вытащивается из арта

### Клавиши

| Клавиша | Действие |
|---|---|
| `Space` / `K` | Играть / пауза |
| `←` `→` | ±5 с (`Shift` — ±15 с) |
| `↑` `↓` | Громкость |

| `S` `R` `M` `L` | Перемешать · повтор · звук · в избранное |

| `/` `?` | Поиск · список клавиш |

## Почему не нагружает ПК

Это было отдельной задачей, а не побочным эффектом:

- **Анимируются только `transform` и `opacity`** — работает композитор, repaint нет.
  Фоновые «пятна» — это статичные градиенты, которые двигаются `translate3d`.
- **`backdrop-filter` ровно на двух панелях** (сайдбар и плеер), они не двигаются.
- **Прогресс-бар** обновляется через `scaleX()`, а ширина читается один раз на
  ресайз — внутри `requestAnimationFrame` обращения к layout нет вообще.
- **Визуализатор ограничен 30 к/с**, останавливается на скрытой вкладке
  (`visibilitychange`) и через 0.9 с после паузы. Буферы аллоцированы заранее,
  градиент и CSS-переменные кэшируются между кадрами.
- **Web Audio создаётся лениво** и только после того, как сервер действительно
  разрешил CORS: `createMediaElementSource` на «загрязнённом» источнике
  заглушил бы звук полностью.
- **Ни одного шрифта или библиотеки с CDN** — системный стек шрифтов, иконки
  инлайновым SVG-спрайтом.
- **Эконом-режим** одной кнопкой выключает фон, размытие, визуализатор и
  анимации появления — и закрывает `AudioContext`.
- `prefers-reduced-motion` уважается.

## Десктоп: установщик Windows (.exe)

Плеер упакован в Electron (`desktop/main.js`) и собирается в настоящий
NSIS-установщик на GitHub Actions, потому что в песочнице GitHub-ассеты
(для скачивания Electron) заблокированы.

- **Готовый установщик:** релиз `v1.0.0`, файл `Aurora-Player-Setup-1.0.0.exe`
  (~112 МБ — Electron везёт с собой Chromium; *в работе* приложение остаётся
  тем же лёгким рендерером, что и веб-версия).
  `https://github.com/zxcwmd/music/releases/download/v1.0.0/Aurora-Player-Setup-1.0.0.exe`
- Собрать заново: `npm run dist:win` (нужна открытая сеть до GitHub).
- CI-воркфлоу: `.github/workflows/windows.yml` — ставит зависимости, гоняет
  тесты и пакует NSIS на `windows-latest`; по тегу `v*` прикладывает .exe к релизу.

Особенности десктоп-версии: страница отдаётся по схеме `app://` (нормальный
origin для CORS к Audius / archive.org), один экземпляр приложения, внешние
ссылки открываются в системном браузере, меню и мультимедиа-клавиши пробрасываются
в плеер (`aurora:media`).

## Проверка

```bash
npm install     # нужен только jsdom для UI-теста
npm test
```

238 утверждений в трёх наборах, все прогоняют **боевой код**, а не его копию:

| Набор | Что проверяет |
|---|---|
| `tests/sources.test.js` (78) | Разбор **реальных** ответов `archive.org/metadata` и Audius `/v1/tracks/trending`, отбор играбельных файлов, сборка URL, таймауты и HTTP-ошибки |
| `tests/player.test.js` (76) | Очередь, перемешивание, три режима повтора, откат при закрытом CORS, избранное/история, громкость, перемотка, таймер сна |
| `tests/ui.test.js` (84) | Настоящий `index.html` + все четыре скрипта в jsdom: клики, клавиатура, переходы, экранирование XSS, гонка «ответ пришёл после смены вида», визуализатор без Web Audio |

Тест гонки проверен мутацией: с исходным багом он падает, с исправлением — проходит.

## Устройство

```
index.html            разметка + SVG-спрайт иконок
assets/app.css        тема, анимации, эконом-режим
assets/js/util.js     форматирование, хранилище, доминирующий цвет обложки
assets/js/sources.js  Audius + Internet Archive, приведение к общей модели трека
assets/js/player.js   <audio>, очередь, Web Audio, визуализатор, Media Session
assets/js/app.js      виды, список треков, панель очереди, полноэкранный режим
```

Оба источника приводятся к одной модели `{id, title, artist, album, duration,
cover, streamUrl, pageUrl, source}`, поэтому весь интерфейс не знает, откуда трек.
Ссылки на потоки Audius подписаны и протухают — плеер сам обновляет их через
`/v1/tracks/{id}` при ошибке; у archive.org адрес постоянный, он кэшируется.

## Если трек не заиграл

- **Audius иногда отдаёт протухшую подпись** — плеер пробует обновить её дважды,
  потом сообщает об этом тостом. Помогает выбрать трек заново.
- **Часть предметов archive.org лежит только в FLAC/SHN** — браузеры их не
  играют. Такой альбом показывает понятную заглушку вместо пустого списка.
- **Если сервер не отдаёт `Access-Control-Allow-Origin`**, плеер автоматически
  перезапускает поток без `crossorigin`: звук останется, но спектр-анализатор
  выключится (нарисуется спокойная декоративная волна).
